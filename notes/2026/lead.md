### Project: Data Acquisition Process (Ticketing System)

**Role:** Test Lead / QA Lead

**Project Description:**\
A SharePoint-based ticketing system designed to automate ticket creation from inbound emails, identify duplicate service requests (SRs), and streamline ticket processing through workflow automation and backend database integration.

**Responsibilities**

- Led test planning and strategy, analyzing business requirements and defining test scope, scenarios, execution timelines, and quality objectives.
- Designed, prepared, and executed 200+ test cases covering functional, integration, regression, and end-to-end workflows.
- Validated automated ticket creation from inbound emails, including email parsing, ticket field mapping, and request processing.
- Tested intelligent service request (SR) deduplication logic to verify duplicate identification, prevent redundant ticket creation, and ensure accurate ticket handling.
- Performed backend database testing using SQL Server 2012, executing SELECT and UPDATE queries to validate ticket records, processing status, and data consistency.
- Tested integration across SharePoint, C# components, WCF services, Angular interfaces, REST APIs, and Nintex workflows.
- Managed a cross-functional team of four QA engineers, assigning testing activities, reviewing test execution results, and monitoring defect resolution.
- Facilitated daily Scrum meetings, tracked testing progress and blockers, and coordinated with development and business teams to support timely delivery.
- Prepared test execution summaries, defect reports, and release-readiness updates for stakeholders.

**Technology Stack:** SharePoint, C#, WCF Services, Angular, REST APIs, Nintex Workflow, SQL Server 2012, Manual Testing, Test Planning, Regression Testing, Agile/Scrum.

### Project: PidiAssist – Conversational AI Assistant (HR & IT Helpdesk)

**Role:** QA Engineer / Test Engineer

**Project Description:**  
A conversational AI-powered assistant designed to automate HR policy queries and IT helpdesk operations. The solution uses NLP and intent recognition to understand user requests, retrieve relevant information from SharePoint, and integrate with ManageEngine ITSM for automated ticket creation, routing, and escalation.

**Responsibilities**
- Defined the QA strategy, test approach, and test scenarios for AI-driven HR policy queries and IT helpdesk ticketing workflows.
- Designed test cases to validate intent recognition, query classification, conversational accuracy, and response relevance across diverse user inputs.
- Tested variations in user queries, ambiguous requests, incomplete information, and unsupported questions to assess conversational robustness.
- Validated escalation handling and fallback mechanisms for unresolved queries, incorrect intent classification, and requests requiring human intervention.
- Tested integration between ManageEngine ITSM and SharePoint to verify ticket creation, routing, status handling, and retrieval of HR policy information.
- Evaluated AI-generated responses for factual accuracy, consistency, relevance, and alignment with approved HR policies and knowledge sources.
- Identified and documented AI-specific defect patterns, including hallucinations, incorrect intent classification, inconsistent responses, and inappropriate fallback behavior.
- Performed functional, integration, regression, and end-to-end testing, collaborating with development and business teams to resolve defects and improve solution reliability.

**Technology Stack:** Conversational AI, NLP, Intent Recognition, ManageEngine ITSM, SharePoint, AI Response Validation, Functional Testing, Integration Testing, Regression Testing.
