## MySQL – Create Products Table

```
CREATE DATABASE shopdb;

USE shopdb;

CREATE TABLE products (
    product_id INT AUTO_INCREMENT PRIMARY KEY,
    product_name VARCHAR(100) NOT NULL,
    description TEXT,
    category VARCHAR(50),
    price DECIMAL(10,2) NOT NULL,
    quantity INT DEFAULT 0,
    status VARCHAR(20) DEFAULT 'Active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### CRUD Operations

1\. Read all products

```
SELECT * FROM products;
```

2\. Read a specific product

```
SELECT * FROM products
WHERE product_id = 1;
```

3\. Insert a new product

```
INSERT INTO products
(product_name, description, category, price, quantity)
VALUES
('Headphones', 'Bluetooth Headphones', 'Accessories', 1800, 12);
```

4\. Update product

```
UPDATE products
SET price = 60000,
    quantity = 12
WHERE product_id = 1;
```

5\. Delete product

```
DELETE FROM products
WHERE product_id = 5;
```
