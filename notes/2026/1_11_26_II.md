# TypeScript Learning Lab – Step by Step with Node.js

## 1. Understand the architecture

#### Understand the TypeScript Execution Architecture

```
       DEVELOPER
           |
           |
           v
 +-----------------------+
 |  TypeScript Source    |
 |                       |
 |      student.ts       |
 |                       |
 |  let name: string     |
 |  let age: number      |
 +-----------------------+
           |
           |
           | Compile
           v
 +-----------------------+
 |  TypeScript Compiler  |
 |                       |
 |       tsc             |
 |                       |
 |  Type Checking        |
 |  Syntax Validation    |
 |  Type Erasure         |
 +-----------------------+
           |
           |
           | Generates
           v
 +-----------------------+
 |   JavaScript Output   |
 |                       |
 |      student.js       |
 |                       |
 |  Standard JavaScript  |
 +-----------------------+
           |
           |
           | Execute
           v
 +-----------------------+
 |     Node.js Runtime   |
 |                       |
 |  JavaScript Engine    |
 |       (V8)            |
 |                       |
 |  Executes JavaScript  |
 +-----------------------+
           |
           |
           v
 +-----------------------+
 |       OUTPUT          |
 |                       |
 |  Welcome to           |
 |  Transflower          |
 +-----------------------+
```

### Execution commands

```
# Compile TypeScript into JavaScript
npx tsc student.ts

# Execute generated JavaScript
node student.js
```

### Understand the responsibilities

| Component    | Responsibility                       |
| ------------ | ------------------------------------ |
| `student.ts` | Developer writes TypeScript          |
| `tsc`        | Checks types and compiles TypeScript |
| `student.js` | Generated JavaScript file            |
| Node.js      | Executes JavaScript using V8         |

TypeScript is a development-time language experience. Node.js executes JavaScript, not the TypeScript type annotations. The compiler removes TypeScript-only type information during compilation.

Remember:

- TypeScript is a superset of JavaScript.
- TypeScript provides static type checking.
- TypeScript compiler converts `.ts` files into `.js` files.
- Node.js executes the generated JavaScript.

## 6. Functions with TypeScript

JavaScript:

```
function add(a, b) {
    return a + b;
}
```

TypeScript:

```
function add(a: number, b: number): number {
    return a + b;
}

let result: number = add(10, 20);

console.log(result);
```

Try calling:

```
add(10, 20);      // Valid
add("10", "20");  // Compile-time error
```

This is one of the biggest advantages of TypeScript.

## 7. Interfaces – Define Student Structure

An interface describes the structure of an object.

```
interface Student {
    id: number;
    name: string;
    email: string;
    course: string;
}

let student: Student = {
    id: 101,
    name: "Rahul",
    email: "rahul@gmail.com",
    course: "TypeScript"
};

console.log(student);
```

If a required property is missing, TypeScript reports an error.

## 8. Classes and Objects

```
class Student {
    id: number;
    name: string;

    constructor(id: number, name: string) {
        this.id = id;
        this.name = name;
    }

    display(): void {
        console.log(this.id);
        console.log(this.name);
    }
}

let s1 = new Student(101, "Rahul");

s1.display();
```

This connects your existing object-oriented programming knowledge with TypeScript.

## 10. Your TypeScript learning roadmap

1. Foundation

   Variables, data types, operators, arrays and functions.

   Start here
2. Object-oriented TypeScript

   Interfaces, classes, constructors, inheritance, access modifiers.
3. Advanced TypeScript

   Generics, enums, union types, type aliases, optional properties.
4. Modules and asynchronous programming

   Import/export, promises, async/await, error handling.
5. Node.js with TypeScript

   Express, REST APIs, middleware, validation.
6. Database integration

   MySQL connectivity, CRUD operations, repository pattern.
7. Testing

   Jest or Vitest, API testing and Playwright with TypeScript.
